CUB Events Calendar

Campus, club, TOS and sports events from the Student Clubs SharePoint, in your own calendar. Tick what you want and add it in one go. Each one shows up as its own calendar, in its own colour, that you can switch on and off any time. New events appear automatically.

Categories

“All Clubs” covers every club. Prefer only some clubs? Untick it and pick them below.

Individual clubs

Clubs appear here once they post an event on SharePoint.

Google Calendar: “Add to Google” opens Google Calendar with everything you ticked; press “Add all”. On a phone, do it once in a browser and it syncs to the app.

Apple Calendar / Outlook desktop: use “Apple / Outlook” next to each calendar; each opens a subscribe prompt.

Outlook web or anything else: “Copy link” and paste it into “Subscribe from web” / “Add calendar from URL”.

Want everything as a single calendar instead? Add “Everything” to Google. That's one checkbox for all events.

Calendars refresh every few hours, so a brand-new event can take a while to appear.
